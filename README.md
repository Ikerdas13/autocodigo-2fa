# AutoCódigo 2FA

Extensión de Chrome que genera tu código de verificación en dos pasos (TOTP) y lo rellena en la pantalla de verificación del inicio de sesión.

- **Política de privacidad:** https://ikerdas13.github.io/autocodigo-2fa/
- **Dudas o problemas:** abre una incidencia en la pestaña [Issues](https://github.com/Ikerdas13/autocodigo-2fa/issues).

Extensión independiente y no oficial.
